# LUNARIS 0.9.1

Финальная адаптивная PWA-сборка Ордена VERBUM DAEMONIS.

## В версии 0.9.1

- улучшена читаемость текста и снижена зрительная нагрузка;
- выровнены размеры, интервалы и контраст на телефоне и ПК;
- языковая панель оформлена в виде `RU — 🇷🇺`, `UA — 🇺🇦`, `KZ — 🇰🇿`, `BY — 🇧🇾`, `PL — 🇵🇱`, `EN — 🇬🇧`;
- добавлена версия приложения 0.9.1;
- кнопка установки оформлена и анимирована;
- добавлены отдельные инструкции установки для iPhone, Android и ПК;
- учтена настройка `prefers-reduced-motion`.

Для геолокации, Service Worker, уведомлений и установки PWA требуется публикация через HTTPS.
