# LUNARIS 1.0.0

Новая кинематографическая PWA-сборка:
- отдельные композиции для ПК и телефона;
- звёзды, туман, лесной горизонт и живая Луна;
- Astronomy Engine с резервными локальными расчётами;
- семь традиционных светил, положения в знаках, высота, азимут и аспекты;
- 24 неравных планетарных часа;
- ход лунного месяца;
- Open-Meteo, геолокация, планировщик и PWA.
