# LUNARIS · VERBUM DAEMONIS

Ритуальный PWA-навигатор, разработанный и созданный Орденом VERBUM DAEMONIS.

## Возможности
- автоматическая геолокация при запуске;
- местное время в реальном времени;
- погода, восход и закат;
- фаза Луны и ближайшее полнолуние;
- планетарные часы;
- простой планировщик практик;
- локальное уведомление за 1 час;
- установка как PWA и офлайн-кэш.

## Запуск
Для геолокации, Service Worker, установки PWA и уведомлений нужен HTTPS или localhost.

```bash
python -m http.server 8080
```

Откройте http://localhost:8080 и разрешите геолокацию и уведомления.

## Ограничение браузеров
Локальный таймер надёжно работает, пока PWA открыто или остаётся активным в фоне. Для гарантированной доставки после принудительного закрытия приложения потребуется серверный Web Push.
